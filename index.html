모아 SNS 스튜디오 개인정보처리방침

시행일: 2026년 9월 15일

이 개인정보처리방침은 모아 SNS 스튜디오 0.1.0에 적용됩니다.

1. 처리하는 정보와 목적

확장 프로그램은 사용자가 입력하는 주제, 작성 가이드, 독자와 말투 설정, 직접 작성한 메모, 참고 자료, 글 초안, 태그, 사진 및 AI 분석 결과를 처리합니다. 해당 정보는 초안 작성·수정·사진 분석·이미지 준비·내보내기를 위해 사용됩니다.

사용자가 현재 탭을 연결하면 해당 탭의 주소와 식별 정보를 작업 연결에 사용합니다. 사용자가 공개 페이지 점검을 실행하면 해당 페이지 주소, 제목, 메타 설정, 링크, 이미지 로드 상태 및 광고 관련 코드 존재 여부를 점검 보고서 작성에 사용합니다. 전체 방문 기록을 수집하거나 자동으로 사이트를 순회하지 않습니다.

2. 저장 위치와 보관

초안·설정·선택한 이미지는 Chrome의 로컬 확장 저장소에 보관됩니다. 연결된 탭 정보는 브라우저 세션 저장소에 보관됩니다. 개발자가 운영하는 별도 서버에 저장하지 않습니다. 초안은 사용자가 새 글 기능으로 삭제하거나 확장 프로그램을 제거할 때까지 남을 수 있습니다. 사용자가 내려받은 파일은 별도 삭제해야 합니다.

3. 외부 서비스로의 전달

사용자가 AI 작업을 실행하면 해당 작업에 필요한 요청 내용·초안·메모 및 사진이 사용자가 선택한 Google Gemini 또는 OpenAI ChatGPT 웹 서비스로 전달됩니다. 자동 전송 선택을 끄면 입력된 요청을 사용자가 직접 확인하고 전송할 수 있습니다. 사진 분석 버튼은 선택한 사진을 AI 서비스로 첨부하는 작업을 시작합니다.

AI 서비스에서는 사용자의 해당 서비스 계정, 설정, 이용약관 및 개인정보처리방침에 따라 정보가 처리됩니다. 모아 SNS 스튜디오의 로컬 삭제가 AI 서비스 대화 기록을 삭제하지는 않습니다. AI 서비스 기록은 해당 서비스에서 관리해야 합니다.

이미지 검색 버튼을 누르면 검색 키워드를 포함한 Google 이미지 검색 페이지가 열립니다. 이미지 가져오기 기능은 AI 응답에 표시된 이미지 제공 주소에 다운로드 요청을 보냅니다. 공개 페이지 점검 결과는 별도의 AI나 개발자 서버로 자동 전송하지 않습니다.

4. 기타 데이터 처리

확장 프로그램은 비밀번호·API 키·결제 정보를 요구하지 않으며, 자체 광고 코드·이용 분석 도구·데이터 판매 기능을 포함하지 않습니다. 처리하는 데이터를 광고 타기팅, 신용 평가 또는 대출 목적으로 사용하지 않습니다. 사용자의 글과 사진을 확장 프로그램 개발자의 모델 학습을 위해 전송하지 않습니다. 외부 AI 제공자의 처리 기준은 각 서비스 정책을 따릅니다.

5. 사용자 선택

사용자는 AI 자동 전송을 끄거나 사진을 제거하고, 새 글 기능으로 저장된 작업을 지울 수 있습니다. Chrome 확장 프로그램 설정에서 사이트 접근 권한을 제한하거나 확장 프로그램을 제거할 수 있습니다. 사이트 접근을 제한하면 해당 사이트의 자동 입력 기능이 동작하지 않을 수 있습니다.
